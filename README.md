# Aether100 Pro Edge AI Workstation Hardware Platform

Open-source Technical Data Package for a silent local edge AI workstation.

**Status:** Rev A – 2026-07-31

## Key Targets
- 150 W continuous power
- Junction temperature ≤ 80 °C
- Noise ≤ 18 dBA
- 256 GB LPDDR5X memory
- Dual 4 TB PCIe Gen5 storage
